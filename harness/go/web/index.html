동시 수준마다 요청을 한꺼번에 보내 처리량(tok/s)과 지연을 잽니다. 접속·모델·시스템 프롬프트는 왼쪽 설정을 씁니다. 공유 서버에는 부하가 가니 작게 시작하세요. 요청 끝에 번호를 붙여 응답 캐시 효과를 줄입니다.

LLM 서버로 보낸 요청 JSON 과 응답 요약을 보여 줍니다. API 키는 헤더로만 보내서 여기에 나오지 않습니다. 같은 줄이 터미널에도 찍힙니다.
